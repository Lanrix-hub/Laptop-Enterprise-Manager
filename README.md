# LaptopEnterpriseManager

> *Система управления предприятием по производству и продаже ноутбуков*

---

## 📋 Описание проекта

**LaptopEnterpriseManager** — консольное приложение на C++, предназначенное для моделирования и управления деятельностью компании, занимающейся производством, поставками и продажей ноутбуков и аксессуаров.

Программа позволяет:
-  Управлять заводами, поставщиками, точками продаж
-  Отслеживать производство и финансовые показатели
-  Рассчитывать прибыль, расходы и доходы с учётом налогов
